# The rules nothing automates

| Rule | API | Check |
| --- | --- | --- |
| No content under the Dynamic Island, notch, status bar or home indicator; the ground runs edge to edge | `react-native-safe-area-context`, never React Native's `SafeAreaView` | `/verify` on both platforms |
| No content under iOS's glass bar, which is laid over the page, in every state of a page under it: opened, the keyboard up on its last field, scrolled to its first fault, and its fallback or not-found view | A scroll view with `contentInsetAdjustmentBehavior="automatic"`, a fallback included; a scroll target less `useHeaderHeight()` on iOS; a keyboard offset that does not come from `measureInWindow` (`FormPage`) | Every page that moved under the bar, each state listed, in one iPhone hand-off: on #87 the user found five faults one round trip at a time |
| The keyboard never hides the field being typed in, its label and its fault, or the action that commits it, and one tap commits | A scroll view with `keyboardShouldPersistTaps="handled"`; `FormPage`'s keyboard avoidance, measured from where the page starts in the window, which `forms/form-page` requires; the button sits outside the scroll view, or the keyboard hides it until a scroll | Driven before sign-off as a table: first and last field at fault, first and second refusal, a focus move that changes the keyboard's kind, text 1.0 and 2.0. Then `/verify` on the iPhone and the emulator |
| A screen shown before a system permission prompt may explain, never imitate it: its button reads "Continue", not "Allow" ([App Review 5.1.1](https://developer.apple.com/app-store/review/guidelines/#data-collection-and-storage)). A refusal is a state on the screen with a route to Settings, never an `Alert` | `Linking.openSettings()` | A screen test per grant state; `/verify` from a fresh install |
| Haptics confirm a deliberate act, never a figure updating and never an entry logged (DESIGN.md, *Asking and telling*) | `expo-haptics` | `/verify` on the iPhone |
| The status bar follows the appearance | `<StatusBar style="auto" />`, once, in `app/_layout.tsx` | `/verify` in both appearances |
| A figure is announced with its unit as a word ("132 grams of protein"), an absence as its words; figure and unit are one element | `accessibilityLabel`, `accessible` on the container | A screen test by label, and a sibling for the absence |
